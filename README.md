# Research Assistant System (RAS)

A production-grade RAG system for academic paper literature surveys with master-slave agentic architecture.

## What it does

RAS helps researchers with literature surveys by:
- Supporting claims with relevant papers from indexed academic papers
- Providing opposing viewpoints from literature
- Using agentic RAG with master-slave architecture for deep paper analysis

Currently building the ingestion pipeline to process academic papers from ArXiv into a searchable vector database.
